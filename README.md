# Grior

A 3D platformer made with [Babylon.js](https://www.babylonjs.com/) as a 2022 school project.

**[Play it](https://ractouf.github.io/web2-2022-project-group-03/)**

## Controls

| Key           | Action             |
| ------------- | ------------------ |
| ZQSD / WASD   | Move               |
| Space         | Jump               |
| C             | Toggle first person |
| Esc           | Pause              |

## Development

```
npm install
npm start      # dev server
npm run build  # production build in dist/
```

Pushing to `main` deploys to GitHub Pages (`.github/workflows/static.yml`).
